# 🐐 GoatRent Developer Hub

Welcome to the official developer organization for **GoatRent** — the peer-to-peer equipment rental and sales marketplace platform.

## 🌍 Platform Overview

Welcome to the GoatRent Engineering Hub. GoatRent bridges the gap between hyper-specialized vertical platforms (Airbnb, Turo) and chaotic legacy classified boards (Craigslist).

Powered by a 100% Serverless Microservices Mesh on Google Cloud Platform, our architecture leverages PostGIS for real-time map clustering, Vertex AI Gemini for photo-first listing generation, and PostgreSQL pgvector for instant semantic search. We unify Daily Rentals, Direct Sales, and Local Services into a single, adaptive transaction engine.
